### 추가 테스트 제안 (구현 없음)

**Domain 보강**

- Fake `UnitCatalog`로 `factorOf()`→0 주입 → `LengthConversionEngine::convert` → `invalid_argument`
- JSON `factorToMeter: "abc"` → `CatalogJsonError`

- `CliApp().run(in,out,err)` 기본 config 경로 (3인자 overload)

- `":2.5"`, `meter!:1` → `InputParser` 단위명 검증
