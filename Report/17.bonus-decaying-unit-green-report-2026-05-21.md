## 1. 수행 작업

Step 16에서 고정한 **DecayingUnit** 보너스 계약에 대해 **GREEN만** 수행했다. OCP 접근: 기존 `Item`·초기 3단위(meter/feet/yard) 분기 수정 없이 `registerUnit`으로 레지스트리(`impl_->items`)에만 추가.

### 1.1 구현 요약

| API | GREEN 동작 |
|-----|------------|
| `registerUnit(name, ratioToMeter)` | `ratioToMeter <= 0` → `std::invalid_argument`; 양수면 `items.push_back` |
| `convert(from, value, to)` | 레지스트리에서 from/to `ratioToMeter` 조회 → `meters = value × fromRatio` → `meters / toRatio` |
| `convertAll(from, value)` | 등록된 모든 `items`에 대해 `convert` 결과 `(name, value)` 벡터 반환 |

### 1.2 제약 준수

| 제약 | 상태 |
|------|------|
| `UnitConverter.cpp` / `Item` 기존 변환 로직 수정 금지 | ✅ 루트 `UnitConverter.cpp` 미변경 |
| `Item` 구조체 필드·의미 변경 금지 | ✅ `name` + `ratioToMeter` 유지 |
| if-else 확장 대신 레지스트리 등록 (OCP) | ✅ 초기 3단위는 `Impl` 초기값, cubit은 `registerUnit`만 |
| REFACTOR 금지 | ✅ `unordered_map`·중복 거절·헬퍼 추출 없음 |

### 1.3 테스트 케이스 (BT-01~06)

| ID | 검증 | GREEN 결과 |
|----|------|------------|
| BT-01 | cubit→meter `0.4572` | PASS |
