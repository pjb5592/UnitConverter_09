## 1. 수행 작업

신규 **감쇠 단위(DecayingUnit)** 보너스 기능에 대한 Catch2 **RED** 테스트와 의도적 실패 스텁을 추가했다. **GREEN 구현은 수행하지 않음.**

### 1.1 기능 계약 (테스트가 고정하는 동작)

| API | 계약 |
|-----|------|
| `registerUnit("cubit", 0.4572)` | 1 cubit = 0.4572 m (`ratioToMeter` = 미터/단위) |
| `convert("cubit", 1.0, "meter")` | `0.4572` (ε≤1e-5) |
| `convert("meter", 1.0, "cubit")` | `1/0.4572 ≈ 2.1872` |
| `convert("cubit", 1.0, "feet")` | `0.4572 × 3.28084 ≈ 1.4997` |
| 음수 비율 등록 | `std::invalid_argument` |
| `convertAll("cubit", 1.0)` | meter/feet/yard/cubit 4행 |
| `convert("meter", 1.0, "feet")` | 기본 3단위 회귀 `3.28084` |

### 1.2 제약 준수

| 제약 | 상태 |
|------|------|
| `UnitConverter.cpp` / `Item` 기존 변환 로직 수정 금지 | ✅ 루트 `UnitConverter.cpp` 미변경 |
| `Item`은 `DecayingUnit.cpp` 내부 전용 | ✅ `struct DecayingUnit::Item` 로컬 정의 |
| 구현 금지 (RED only) | ✅ `convert`→0, `convertAll`→{}, `registerUnit` no-op |

### 1.3 테스트 케이스 (BT-01~06)

| ID | SECTION | 검증 |
