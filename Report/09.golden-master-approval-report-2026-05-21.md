## 1. 수행 작업

Step 08(F02·커버리지 게이트) 이후, **unit_converter CLI stdout**을 기준으로 고정하는 **Approval / Golden Master** 회귀 체계를 도입했다.

### 1.1 기준 파일·캡처 전략

| 항목 | 내용 |
|------|------|
| **기준 경로** | `tests/golden_master_expected.txt` (Git 버전 관리 필수) |
| **입력 시나리오 4개** | `meter:2.5` · `feet:1.0` · `yard:1.0` · `meter:0.0` |
| **캡처** | 시나리오별 `unit_converter` stdin 리디렉션; 프롬프트 줄 제외, 변환 줄만 `[입력]` 블록으로 묶음 |
| **구분자** | 시나리오 간 `---` |

### 1.2 Approve 패턴 (Catch2)

| 조건 | 동작 |
|------|------|
| 기준 파일 **없음** | 현재 캡처로 `golden_master_expected.txt` 자동 생성 + WARN |
| 기준 파일 **있음** | `actual` vs `expected` 문자열 전체 비교 |
| **불일치** | 줄 단위 diff를 stderr에 출력 후 **FAIL** |

### 1.3 산출 스크립트

| 스크립트 | 용도 |
|----------|------|
| `scripts/generate_golden_master.ps1` | Windows — 기준 파일 재생성 |
| `scripts/generate_golden_master.sh` | Linux/macOS/Git Bash |

### 1.4 출력 LOCK 참고

- 요청 예시의 `8.202100`/`2.734025`는 **ConversionUseCase·6자리 계약**(Track A RED).
- **CLI(`src/main.cpp`)** 는 `roundOneDecimal`(ROUND-LOCK 1자리) → 기준 파일은 **실측** `8.2 feet` / `2.7 yard` 등으로 고정.
